# Reporting a security issue

Please do not report an exploitable vulnerability in a public issue or pull request. Use GitHub's private vulnerability reporting for this repository when it is enabled. If the private report option is unavailable, contact the repository owner through the GitHub profile and request a private channel before sending technical details.

Include the affected commit or release, impact, and minimal reproduction steps. Do not include live credentials, customer records, wallet secrets or personal data. MEW's public demo is simulation-only; never test against a live wallet or payment endpoint.

The repository owner should acknowledge reports privately, coordinate a fix and disclosure date, and publish a sanitized advisory after affected users have a mitigation. Do not assume private vulnerability reporting is enabled until verified in GitHub repository settings.
