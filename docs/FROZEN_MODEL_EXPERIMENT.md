## Actual local inference results

The pinned model download completed and MLX GPU inference succeeded. All twelve base answers were generated locally: 0/12 satisfied the strict JSON contract; 7/12 received their exact supporting span, and four reached the 256-token cap. Independent agent review identified a false settlement-proves-delivery claim, fabricated source quotations, wrong-language output and missing answers. Source retrieval misses and first-4000-character truncation are separate pipeline failures.

A diagnostic `--variant prompt-v2` run supplied complete retrieved documents, an explicit concise JSON schema and a 512-token cap. It achieved 1/12 strict-contract outputs and supplied exact supporting spans for 8/12. Its one schema-valid answer is semantically wrong, so schema success is not a safety or quality pass. Multiple conditions changed together; no improvement is attributed to one isolated cause. Both raw runs are preserved. Neither run is suitable for deployment. No adapter was trained: genuine human-approved, disjoint training examples remain required. The experiment summary and failure-training plan record these limits.
