# Multilingual reliability knowledge map

Reviewed 7 October 2026. These sources inform engineering experiments; their contents are not an approved training dataset. This review installed no dependencies, downloaded no video, and observed no YouTube transcript. Model cards describe publisher capabilities, not demonstrated MEW performance. Exact model revisions and installed-library behavior must be recorded in experiment receipts.

The starting failures are documented in [FROZEN_MODEL_EXPERIMENT.md](FROZEN_MODEL_EXPERIMENT.md): twelve agent-labeled development cases exposed French retrieval failures, invalid output contracts and incorrect answers. More references or agents do not establish improvement. Keep retrieval, context coverage, syntax validity, citation entailment, language fidelity and authority compliance as separate measurements.

## Pitfalls still requiring experiments

1. **Two different truncation points.** Encoder token limits and generator context budgets differ. Record encoder input token counts, chunk/source offsets and final generator evidence coverage. Character counts alone do not prove token fit, particularly across languages.
2. **Pooling and prompt mismatch.** Save the exact model/configuration revision, pooling, normalization, query/document prompts and similarity function with every index. Rebuild corpus embeddings when these change. Reject vectors with wrong dimensions, NaN values or incompatible model provenance.
3. **Cross-language semantic near misses.** French terms for reservation, exposure and settlement can retrieve nearby concepts without the decisive negation or qualification. Add fresh expert-reviewed adversarial cases for “payment settled” versus “delivery verified,” unknown versus failed, and preprod versus mainnet. These are proposed MEW tests, not measured external-paper results.
4. **Ranking is not confidence.** Do not promote a high cosine value into payment proof or answerability. Evaluate no-evidence queries and abstention independently; any threshold requires calibration on a separate reviewed set.
5. **Noisy context and conflicting versions.** Test duplicated chunks, stale specifications, contradicted passages and distractors. Preserve source hashes and temporal provenance; an embedding match does not authenticate the text or give it operational authority.
6. **Benchmark reuse and judge leakage.** Keep EN/FR translations in the same lineage group. Repeated tuning against twelve development cases cannot demonstrate customer generalization. Add disjoint human-reviewed pilot questions and report how subjective evaluators agree with those reviewers.
7. **Reference rights remain separate.** Repository code licenses, model weight licenses and dataset/media reuse permissions are different records. A permissive model license does not approve fine-tuning on YouTube, social posts or blogs. No external text in this map was exported as a training example.

## Specialist handoff

The retrieval specialist returns an immutable corpus/index receipt and per-language ranking/context results. The output specialist returns raw responses plus syntax, citation and abstention checks. The review specialist returns labeled failure traces with reviewer type and lineage. The lead compares these artifacts against the same experiment ID; disagreement remains visible. All model outputs remain advisory. Deterministic accounting and authenticated evidence boundaries continue to govern economic actions.

Acceptance means a reproduced improvement without regression on authority checks, followed by fresh pilot evaluation. This map is research guidance, not a claim of deployment, model training, video analysis or universal multilingual coverage.
