# MEW workflow continuity

The website has two distinct example journeys, defined by
`public/workflow-context.js`. Understand → Try → Verify → Plan uses the same public
`workflow=report|clips` selector. Report uses one report, Alpha 1.50 ADA, Beta 1.40
ADA and a 3 ADA limit. Clipping uses one five-outline bundle, Editor A 8 ADA,
Editor B 6 ADA and a 10 ADA limit. The clipping combined price exceeds its limit;
the report combined price does not. Both preserve occupied quantity on timeout.

Marketing connects to the existing campaign rehearsal, team responsibilities,
source library, evidence explorer and pilot planner. The company explanation maps
planning, production, independent review and measurement onto existing configured
roles. It does not alter company profiles, skill fingerprints or grant tools.
Use `.agents/skills/mew-marketing-workflow/SKILL.md` for host planning and review.

Only an allowlisted example choice travels in links. No customer text, receipt,
auth token, reservation, exposure, model response or economic authority is passed.
There is no session/local-storage synchronization. Fixed report/clip demo pages
ignore conflicting selectors so a label cannot change the real fixture. Pilot
selection updates contextual routes and placeholders; customer text stays in the
tab. Editing any field invalidates a prepared draft. It is never submitted.

Homepage decisions run in a private browser simulation. Studio/campaign records
are public shared demo state and coordinate presenter changes. Evidence is an
explanation, not a synchronized live ledger view. Returning to a page does not
prove completion; current step follows the route, not a progress certificate.

Models, real media production, ad accounts, publishing and payment execution
remain disconnected. Separate source rights, actual artifact acceptance, ad
budget authorization and measured customer outcomes are needed for a real pilot.
Private database login, approved signer custody, funding and independent audit
remain production gates. Navigation cannot satisfy them.
