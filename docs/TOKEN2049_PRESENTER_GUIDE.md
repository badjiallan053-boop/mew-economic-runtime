# Presenting MEW

This presentation is a working local prototype, not a live paid service or an official TOKEN2049 partnership. Open `/home.html` on the MEW server, or `/` for the same presentation. `npm start` uses the configured application database; for an isolated rehearsal, set `MEW_DB_PATH=.local/token2049-preview.sqlite`, `HOST=127.0.0.1` and an available `PORT` before starting. The homepage example itself is entirely ephemeral.

## Six-minute walkthrough

1. **Problem, 40 seconds:** “A team of agents can retry the same purchase through different suppliers. MEW keeps one purchasing objective and its commitments visible to all of them.” The illustration represents a shared boundary, not live network activity.
2. **Decision, two minutes:** Click See the decision. Reserve Alpha's 1.50 ADA report, record the unknown outcome, then request Beta's equivalent 1.40 ADA report. Point out that 2.90 ADA fits the 3 ADA cap. Beta waits because the first request still occupies the one-report objective. No payment occurs.
3. **Evidence, one minute:** Separate deterministic accounting from advisory model experiments. Expanded evidence coverage and response format passed 12 development cases; grounding and language quality still block model activation. Cardano drafts remain unsigned and a funded preprod lifecycle and external contract audit are pending.
4. **Integration, one minute:** Open The proof to inspect existing protocol boundaries. A wallet or payment rail does not decide whether the second report is admissible, and settlement does not prove accepted delivery. The persisted decision studio is a separate workspace from the local homepage example.
5. **Next action, one minute:** Open Pilot with us. Scope one deliverable, one owner and one retry failure. The planner downloads a reviewable brief; it does not submit an application, contact customers or authorize spending.

Restart clears this tab's example. Pause motion stops the decorative artwork. For a conference connection failure, keep the already-running local server available and rehearse the demonstration before presenting; the website build includes the kernel, fonts and illustration locally.
