## Critical path

1. Assign one pilot/product owner, one release owner and one independent security reviewer. Privately record names and alternates. Confirm one consenting customer and rights to a small source asset. Avoid expanding scope beyond one five-clip pilot.
2. Configure entitled model access privately and approve a separate model spending limit. Run the existing live evaluation, review unsupported claims and structured-output failures, then add held-out authorized customer cases and six-task workflow evaluation. Four fixtures alone cannot establish quality. Failures must block promotion.
3. Produce actual clip files through a selected tool/provider and record exact hashes, revisions, customer acceptance, elapsed time and actual cost. Current synthetic outlines do not produce video. Establish the provider's real API, entitlement, license and error behavior before building a media adapter.
4. The private HTTP factory implements bounded reserve/read/delivery routes and a loopback launcher with private configuration checks; deploy and provision it separately with TLS, token lifecycle, bounded request bodies, rate limiting, sanitized errors, separate private storage and reviewed key enrollment. Rehearse unauthorized principal, revoked key and restart scenarios. Do not expose the raw store or mix customer records with public demo data.
5. Integrate one real external job with durable identity and explicit reconciliation. The live dispatcher is still missing. A timeout retains exposure; reconcile the original job rather than retrying submission. Validate real provider receipts against trusted preaccepted artifact contracts.
6. Only then connect preprod MPS: exact deployed release/spec compatibility, migrations and encryption-key recovery, scoped credentials, approved signer custody, funded address and exact token unit. Native tokens require asset-aware admission/accounting before entering the lovelace ledger. Implement bounded dispatch and independent settlement verification; prove collection plus delivery, then test restart and laptop-off operation.

Steps 1–3 create customer value without waiting for payments. Steps 4–6 establish authenticated economic execution. No defensible deadline for the full lifecycle exists until credentials, provider interface and customer availability are confirmed.

## Work that can proceed without credentials

Prepare a held-out customer rubric and evidence template; specify the private operator API and credential rotation procedure; choose and inspect one media provider; extend six-task evaluation coverage; define asset-aware accounting before token payment integration; add atomic research snapshot promotion before scheduled refresh. Prioritize these over additional agent roles or broad scraping.

## Evidence required to call the result complete

One consenting customer; actual artifacts accepted by an authorized reviewer; measured model quality and billed cost; authenticated provider delivery bound to the reserved objective/effect/job; verified exact-asset preprod seller collection; restart recovery without duplicate spend; tested backup recovery; named operational owners and reviewed deployed commit. Each is a separate gate—hosting health or agent recommendations cannot substitute for it.
