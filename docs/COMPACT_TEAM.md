# Compact evidence-to-decision team

Five active roles, six tasks; no automatic specialist fan-out.

Scope coordinator → evidence curator → builder proposal → independent risk and
adversarial reviews → coordinator synthesis. Risk and red team see the same
accepted proposal and original evidence; neither sees its peer's judgment.
Dependency outputs are advisory claims. Only supplied catalog IDs may be cited.
The coordinator must preserve unresolved blockers instead of voting them away.

The compact profile is the new UI and rehearsal CLI default. The CompanyRuntime
constructor retains its full default for API compatibility. Existing discovery,
release, paid-readiness and full plans, prompts, skill sets and policy digests are
unchanged. No saved mission migrates to compact. Use a separate compact journal.

Run `npm run company:rehearse`. This executes six synthetic tasks, not model calls.
The enhanced role prompts live in prompts/company/compact. Their purpose-specific
instructions cover scope, evidence uncertainty, interface identity/units/schema,
negative checks, recovery and consumer validation. Strict seven-field advisory
outputs, timeout/UNKNOWN behavior and financial boundaries remain authoritative.
The new handoff-review procedure is loaded as reference-only for compact roles
and included in that profile's policy digest. No tool privileges are added.

## Knowledge selection

The overlooked capability is evaluation and consumer validation, not more roles.
Reviewed [agentic-eval](https://www.skills.sh/github/awesome-copilot/agentic-eval)
and its [actual SKILL.md](https://github.com/github/awesome-copilot/blob/main/skills/agentic-eval/SKILL.md).
It describes separated generation/evaluation, bounded refinement and structured
assessment. Reference only: mutable main is unpinned; license/dependency package
not fully reviewed, no installer or external code adopted. MEW does not implement
its executable examples or assume a generic score proves safety. The local
handoff-review skill is original and adapts observable acceptance, baseline and
bounded-work principles to MEW's existing host contracts.

No model quality improvement is claimed without real-provider comparative
measurements. Credentials and billing gates remain pending. MCP/A2A transport,
paid dispatch, media generation and analytics remain separate unimplemented gates.
