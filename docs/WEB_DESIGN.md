# MEW Web3 website redesign

The user rejected the prior bright mascot-led site. This release uses an original economic-mandate graphic, a midnight workspace palette and an immediate path into the decision demo. It does not add wallet connectivity, model execution or payment dispatch.

## Studio responsibilities

Homepage author: web3_design. Shared navigation and workspace styling: web3_shell. Independent claim, accessibility and journey reviewer: web3_review. Lead: integration, architecture explorer, research-page styling, demo reordering, rendered checks and release verification. These are implementation contributors, not newly deployed runtime agents.

Two critique rounds covered storyboard and completed source/rendered pages. Corrections included moving decision controls before decorative formation, precise lovelace wording, mobile 44px controls, diagram semantics and filled-CTA contrast. The homepage illustration is local explanatory state only; the decision studio remains the existing persisted synthetic rehearsal with unchanged API contracts.

## Design system

Midnight #090e1a, panel #111a2b, line #2b3950, text #edf3fa, muted #acb9cc, mint #9af0d1 and lilac #bba7ff. Architecture explorer uses closely related ink/mint tokens. System typography avoids third-party font requests. Display typography carries the main claim; monospace is reserved for compact diagram/state annotations. Motion is restrained and respects reduced-motion preferences. No new external runtime dependency, copied website implementation or partner endorsement.

Journey: understand the shared mandate on Overview → run a synthetic decision → inspect advisory versus economic authority on Architecture → inspect source provenance on Evidence. Workflows, Design studio and Clip rehearsal remain available through navigation. Live models, customer validation and payment activation remain pending and visibly labeled.
