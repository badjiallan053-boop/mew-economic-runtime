# Handoff and evaluation procedure

Original local procedure. Read AGENTS.md and docs/COMPACT_TEAM.md.

1. Identify producer, consumer, host task IDs and supplied evidence catalog.
2. Record fact, assumption, conflict and missing input separately.
3. Preserve schema, immutable identity, units, actor scope and exact artifact version.
4. Challenge timeout, duplicate/replay, substitute source and restart cases.
5. Evaluate against observable acceptance and a declared baseline; model agreement
   is not factual proof. Mark unrun tests and infrastructure failures explicitly.
6. Limit refinement to the host-selected work package. No automatic retry, new
   delegation or tool installation. Reconcile uncertainty before external action.
7. Return only the strict advisory contract; host owns authorization and admission.

Source discovery: GitHub awesome-copilot agentic-eval via skills.sh, reviewed as
reference. No external code copied, installer run or model quality measured.
