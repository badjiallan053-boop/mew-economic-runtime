# Company product and delivery review

Original local procedure. Read AGENTS.md, SPEC.md and docs/AI_NATIVE_COMPANY_PLAN.md.

1. State the customer, job, observed problem and assumptions. Never fabricate research.
2. Define the outcome, acceptance evidence, cost ceiling and permitted external actions.
3. Compare reuse with one alternative; rank by user value, uncertainty, recovery and cost.
4. Assign existing responsible producer, independent reviewer and acceptance owner.
5. Select only reviewed task-relevant skills; record source revision and authority limits.
6. Specify contracts, negative tests, accessible UI states and operational recovery.
7. Separate synthetic/provider execution, advice/authority and payment/delivery evidence.
8. Record measured outcomes, unresolved blockers and the next falsifiable experiment.

This procedure grants no tools, publishing rights, purchases or credential access.
It is host planning guidance; changing provider skill contexts requires a separately
reviewed policy change and cannot reinterpret a saved mission.
