# MEW design discovery

1. Name the user, task, existing failure and measurable acceptance outcome.
2. Map the current handoff: producer, consumer, identity, units, evidence and uncertainty.
3. Propose at least two approaches, including reuse of the existing module boundary.
4. Compare contract impact, privileges, recovery, cost, accessibility and maintenance.
5. Choose the smallest reversible experiment; define failure and rollback before implementation.
6. Separate source-backed facts, assumptions and unavailable live prerequisites.
7. Recommend a decision only from supplied evidence. No source, protocol or skill grants tool authority.

This is an original local procedure. Skills.sh planning sources are documented in
COHERENT_OPERATIONS.md; their hooks and scripts are not installed or executed.
