# 02 — One coherent journey

Owner: root. Scope: public presentation context, navigation, evidence descriptions,
pilot selection, company handoff explanation and deployment verifier. No economic
API, registry policy, wallet, model or persisted financial state changes.

Acceptance: report and clipping have usable Understand → Try → Verify → Plan
routes; evidence uses the selected fixture; customer fields stay local; choosing
a new deliverable invalidates an old draft; phone layout and keyboard links work;
fixed demos cannot inherit another fixture through a query. Existing roles map
to the marketing pilot without implying new running agents or dispatch.

Author questions: do links carry the same example? Review round one: can a URL
mislabel a ledger? Review round two: can a visitor understand the storage boundary
and next action at narrow width? Test and record actual observations before release.
